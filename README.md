# Wikan Priambudi — Portfolio Site

Personal portfolio website showcasing my work as an AI/ML Engineer, built with Next.js and TypeScript.

🔗 **Live:** [portfolio-site-inky-eta.vercel.app](https://portfolio-site-inky-eta.vercel.app)

## Features

- **About** — background, skills, and experience summary
- **Projects** — showcase of AI/ML and software engineering work
- **Blog** — writing on AI, machine learning, and engineering topics
- **Contact form** — direct way to get in touch
- **Dark mode** — light/dark theme toggle

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Deployed on [Vercel](https://vercel.com)

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/wikan1602/portfolio-site.git
cd portfolio-site
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser. The page auto-updates as you edit files in `app/`.

## Project Structure

```
portfolio-site/
├── app/            # Next.js App Router pages and layouts
├── components/     # Reusable UI components
├── public/         # Static assets
├── next.config.ts
└── package.json
```

## Deployment

This project is deployed on [Vercel](https://vercel.com), connected to the `main` branch for automatic deployments on push.
